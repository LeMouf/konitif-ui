# Repository agent rules

- Do not install or download dependencies without explicit user approval.
- Keep this package a projection of public Workbench contracts; do not move workspace authority, hosted domain modules, external-system adapters or renderer ownership into UI.
- Keep `README.md` consumer-facing; contributor, release, qualification and agent instructions belong in their dedicated files.
- Build and verify the exact source archive before any release operation.
- Do not commit, push, tag or publish without explicit user approval.
